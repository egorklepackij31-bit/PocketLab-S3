# IncognitoX

Прошивка для карманного мультитула на ESP32-S3. Дисплей ST7789 240x320 стоит вертикально, интерфейс на русском, управление пятью кнопками. Внутри: Wi-Fi, Bluetooth, Sub-GHz 433 МГц, NFC/RFID, инфракрасный приёмник и передатчик, GPS с офлайн-картой Минска, игры, файловый менеджер и онлайн-сервисы.

Проект собран под ESP32-S3-DevKitC-1 N16R8. Питание от Li-Po через TP4056 и AMS1117.

## Что умеет

- Сканирование Wi-Fi, вардрайвинг с GPS, монитор эфира.
- Поиск BLE-устройств и трекеров.
- Анализ 433 МГц, приём и повтор пультов, спектр.
- NFC/RFID: чтение UID, работа с NTAG и MIFARE.
- ИК: приём кодов, универсальный пульт.
- GPS: координаты, качество, запись трека, карта Минска с точками и масштабом.
- Онлайн через Wi-Fi: погода, самолёты ADS-B, МКС, компас по ветру и курсу GPS.
- Игры, файлы на microSD, самотест, настройки, журнал.

Опасные функции из ТЗ (деаутентификация, перехват рукопожатий, поддельные точки доступа, глушилки, клонирование ключей) в прошивку не включены. В меню на их месте выводится пояснение.

## Состав проекта

```
IncognitoX/
  platformio.ini        настройки сборки
  include/              пины, шрифты, секреты Wi-Fi
  src/hw/               дисплей, кнопки, SD, питание, GPS
  src/lib/              драйверы CC1101, NRF24, RC522, PN532, IR, NMEA, сеть
  src/screens/          экраны интерфейса
  sd/                   файлы для копирования на microSD
  tools/                генератор шрифтов и карты
  docs/                 инструкции
```

## Быстрый старт

1. Установите VS Code и расширение PlatformIO.
2. Откройте папку `IncognitoX` через PlatformIO.
3. Подключите плату USB-кабелем.
4. Соберите проект: `pio run -e incognitox`.
5. Загрузите прошивку: `pio run -e incognitox -t upload`.
6. Скопируйте содержимое `sd/` на microSD.
7. Вставьте карту и нажмите RESET.

Подробно про драйверы, COM-порт и режим загрузки: [docs/UPLOAD.md](docs/UPLOAD.md).

Схема пайки и порядок сборки: [docs/SOLDERING.md](docs/SOLDERING.md).

Раскладка microSD и настройка Wi-Fi: [docs/SD_CARD.md](docs/SD_CARD.md).

## Управление

| Кнопка | Действие |
|--------|----------|
| UP / DOWN | перемещение по списку, параметры |
| LEFT | назад, а в карте - сдвиг влево |
| RIGHT | вперёд, а в карте - сдвиг вправо |
| OK | выбор, подтверждение |
| OK (удержание) | второе действие, в карте - смена масштаба |
| LEFT (удержание) | выход из просмотра карты |

## Экран и шрифты

Дисплей работает в портретном режиме 240x320. Отрисовка потоковая, без фреймбуфера, поэтому хватает штатного ОЗУ. Шрифты Roboto содержат латиницу и кириллицу. Все подписи меню на русском.

## Сборка без VS Code

```powershell
pio run -e incognitox
pio run -e incognitox -t upload --upload-port COM5
pio device monitor -b 115200
```

Если PlatformIO не в PATH, используйте полный путь к `pio.exe` или скрипты `build.ps1` и `flash.ps1`.

## Версии

- PlatformIO Core 6.x
- Espressif32 Arduino core 3.x
- ESP32-S3-DevKitC-1 N16R8, flash 16 МБ
- ST7789 240x320 SPI

## Лицензия и данные карт

Код можно использовать и менять свободно. Карта собрана из тайлов OpenStreetMap, при публикации скриншотов указывайте: (c) OpenStreetMap contributors. Шрифты Roboto распространяются по лицензии Apache 2.0, файл лицензии лежит в `tools/fonts/OFL.txt`.
