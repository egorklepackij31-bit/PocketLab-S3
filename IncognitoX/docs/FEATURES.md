# Функции и управление

## Главное меню

Список модулей с иконками. Акцентный цвет меняется в настройках, по умолчанию оранжевый на чёрном.

- О программе

## Wi-Fi

Сканер сетей, скрытые SSID, сохранение в CSV, вардрайвинг с GPS, монитор эфира и поиск BLE-трекеров. Опасные действия не реализованы: на их месте открывается экран с пояснением.

## Bluetooth

Поиск BLE-устройств, сортировка по уровню сигнала, определение трекеров AirTag, SmartTag, Tile и похожих.

## Sub-GHz 433 МГц

Анализ спектра, приём OOK-кодов, декодирование, сохранение в `/subghz`, повтор записанного кода. Работает с CC1101 и антенной 433 МГц.

## Сканер 2.4 GHz

Проверка эфира через NRF24L01: каналы, активность, поиск устройств. Передатчик не используется для помех.

## NFC / RFID

Чтение UID, SAK, работа с NTAG и MIFARE, сохранение дампов. Клонирование и подбор ключей отключены.

## ИК

Приём кодов NEC, Samsung, LG и других, универсальный пульт, повтор из сессии. Передатчик на GPIO15.

## GPS и карта

- Живые координаты, высота, скорость, курс.
- Качество привязки, число спутников, HDOP.
- Запись трека в CSV.
- Офлайн-карта Минска с масштабом и точками.

Управление картой:

| Кнопка | Действие |
|--------|----------|
| LEFT / RIGHT | сдвиг по горизонтали |
| UP / DOWN | сдвиг по вертикали |
| OK | поставить точку в перекрестие |
| OK (удержание) | сменить масштаб |
| LEFT (удержание) | выйти |

Точки хранятся в `/maps/waypoints.csv` и остаются после перезагрузки.

## Онлайн

Нужен Wi-Fi из `/wifi.txt`.

- Соединение: статус, IP, уровень сигнала.
- Погода: температура, ощущение, влажность, давление, ветер.
- Самолёты: ADS-B на радаре в радиусе 60 км.
- МКС: положение, высота, дальность, видимость.
- Компас: направление ветра и курс GPS. Без интернета не работает.

## Игры

Змейка и Тетрис, управление кнопками.

## Файлы

Просмотр microSD, текстовые файлы, карты, удаление и информация о размере.

## Система

Информация о чипе, самотест, скан I2C, список SPI-устройств, UART-мост, веб-страница с данными, журнал.

## Настройки

Яркость, звук, акцентный цвет, часовой пояс, автосон, сплэш при загрузке.
