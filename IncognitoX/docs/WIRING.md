# Справочник по пинам

Полная инструкция по пайке: [SOLDERING.md](SOLDERING.md).

Плата: ESP32-S3-DevKitC-1 N16R8. Дисплей: ST7789 240x320, портрет.

## Общая шина SPI

SCLK GPIO12, MOSI GPIO11, MISO GPIO13. У каждого устройства свой CS.

| Устройство | CS | Другие линии |
|------------|----|--------------|
| TFT ST7789 | 10 | DC 9, RST 2, BL 8 |
| MicroSD | 5 | - |
| CC1101 | 6 | GDO0 7, GDO2 16 |
| RC522 | 21 | RST 42 |
| NRF24L01 | 18 | CE 46 |

## I2C

| Линия | GPIO |
|-------|------|
| SDA | 40 |
| SCL | 41 |

PN532 в режиме I2C, адрес 0x24. IRQ не подключён.

## Остальные линии

| Назначение | GPIO |
|------------|------|
| ИК-приёмник | 1 |
| ИК-передатчик | 15 |
| Пьезопищалка | 4 |
| GPS RX платы | 17 |
| GPS TX платы | 47 |
| Делитель батареи | 3 |
| Кнопка UP | 35 |
| Кнопка DOWN | 36 |
| Кнопка LEFT | 37 |
| Кнопка RIGHT | 38 |
| Кнопка OK | 39 |

Кнопки замыкаются на GND, внутренняя подтяжка включена.

## Питание

| Линия | Назначение |
|-------|------------|
| VIN | 5 В от USB или повышающего модуля |
| 3V3 | питание модулей |
| GND | общий провод |

Делитель батареи: 100 кОм от плюса аккумулятора на GPIO3, 100 кОм с GPIO3 на GND. Прошивка умножает измеренное напряжение на 2.

## Режим PSRAM

По умолчанию PSRAM выключен, потому что на N16R8 octal PSRAM занимает GPIO33-37, а на 35/36/37 висят кнопки. В этом режиме кнопки: 35, 36, 37, 38, 39.

Если включаете PSRAM, задайте `IX_USE_PSRAM=1`. Кнопки автоматически переезжают на 38, 39, 0, 14, 48. Учтите, что GPIO0 влияет на режим загрузки, кнопку LEFT лучше не удерживать при старте.
