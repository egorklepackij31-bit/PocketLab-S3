# Как загрузить прошивку на устройство

Инструкция для Windows. Плата ESP32-S3-DevKitC-1 N16R8, USB-кабель с передачей данных, не только зарядка.

## 1. Установите инструменты

1. Скачайте и установите [Visual Studio Code](https://code.visualstudio.com/).
2. В VS Code откройте раздел Extensions и установите расширение **PlatformIO IDE**.
3. Дождитесь, пока PlatformIO скачает платформу Espressif32 и компилятор. Это занимает 10-20 минут при первом запуске.
4. Установите драйвер USB-UART **CH343** от WCH, если плата определяется как неизвестное устройство. На Windows 11 драйвер часто ставится автоматически.
5. Проверьте наличие Git for Windows. PlatformIO использует его при установке платформы.

## 2. Откройте проект

1. В VS Code нажмите **File - Open Folder**.
2. Выберите папку `IncognitoX`.
3. Дождитесь индексации проекта. В левом нижнем углу появится значок PlatformIO.

Если проект открыт правильно, в терминале PlatformIO команда `pio run` будет искать `platformio.ini` в текущей папке.

## 3. Подключите плату

1. Подключите ESP32-S3 к компьютеру USB-кабелем.
2. Откройте **Диспетчер устройств** и найдите COM-порт, например `COM5` или `COM14`.
3. Если порт не появился, проверьте кабель и драйвер CH343.
4. Закройте программы, которые могут занимать порт: монитор порта Arduino IDE, другие терминалы.

Проверить порт из терминала:

```powershell
pio device list
```

В выводе будет строка вида `COM5` и описание `USB-Enhanced-SERIAL CH343`.

## 4. Соберите прошивку

Откройте терминал PlatformIO и выполните:

```powershell
pio run -e incognitox
```

Или запустите `build.ps1` из папки проекта.

Успешная сборка заканчивается строкой `SUCCESS` и таблицей с расходом памяти. Если появились ошибки, проверьте, что в проекте нет русских букв в пути и что Git доступен в PATH.

## 5. Загрузите прошивку

```powershell
pio run -e incognitox -t upload
```

Если порт не определился автоматически, укажите его явно:

```powershell
pio run -e incognitox -t upload --upload-port COM5
```

Или запустите `flash.ps1`, предварительно поправив номер COM-порта в скрипте.

## 6. Если плата не входит в режим загрузки

Некоторые платы не перезагружаются автоматически. Тогда:

1. Зажмите кнопку **BOOT** на плате.
2. Нажмите и отпустите **RESET**.
3. Отпустите **BOOT**.
4. Повторите команду загрузки.

После прошивки нажмите **RESET** один раз.

## 7. Монитор порта

```powershell
pio device monitor -b 115200
```

В логе видно версию прошивки, результаты самотеста и ошибки модулей. Выход из монитора: `Ctrl+C`.

## 8. Подготовьте microSD

1. Отформатируйте карту в FAT32. Для карт больше 32 ГБ используйте стороннюю утилиту, например SD Card Formatter.
2. Скопируйте содержимое папки `sd` в корень карты.
3. Должны получиться файлы:

```
/wifi.txt
/maps/minsk.bmp
/maps/minsk.geo
```

4. Вставьте карту в устройство до включения.
5. При первом запуске прошивка сама создаст папки `/logs`, `/wardrive`, `/subghz`, `/ir`, `/maps`.

## 9. Настройте Wi-Fi

Откройте `/wifi.txt` на карте в блокноте и впишите свои данные:

```
ssid=МояСеть
pass=МойПароль
```

Сохраните файл в кодировке UTF-8 без BOM. Затем в меню устройства откройте `Онлайн - Соединение` и нажмите OK.

Можно вместо карты прописать сеть в `include/secrets.h`, но файл на карте имеет приоритет.

## 10. Проверка после прошивки

1. Нажмите RESET. Появится логотип IncognitoX и строка самотеста.
2. Проверьте, что экран не перевёрнут. Если перевёрнут, измените `TFT_ROTATION` в `include/config.h` на 0 или 2.
3. Пройдите по меню кнопками UP, DOWN, OK.
4. Откройте `GPS / Map - Карта Минска (офлайн)`. Карта должна рисоваться и двигаться кнопками.
5. Проверьте кнопки: LEFT возвращает назад.
6. Откройте `Онлайн`, подключитесь к Wi-Fi и проверьте погоду.

## 11. Частые проблемы

| Симптом | Что делать |
|---------|------------|
| `Could not open COM5` | Порт занят другой программой или указан неверно |
| Плата не определяется | Замените USB-кабель, установите драйвер CH343 |
| Ошибка `Failed to connect` | Зажмите BOOT и нажмите RESET, повторите загрузку |
| Сборка падает на Git | Установите Git for Windows и перезапустите VS Code |
| Прошивка загрузилась, но экран тёмный | Проверьте BL, питание дисплея и rotation |
| Устройство перезагружается | Слабое питание, проверьте аккумулятор и 3.3 В |
| Wi-Fi не подключается | Проверьте SSID, пароль и диапазон 2.4 ГГц |
| Карта не открывается | Проверьте путь `/maps/minsk.bmp` и формат BMP 24 бита |

## 12. Полная очистка флеша

Если плата ведёт себя странно после нескольких прошивок, сотрите флеш и загрузите снова:

```powershell
pio run -e incognitox -t erase
pio run -e incognitox -t upload
```

Все пользовательские файлы на microSD останутся на карте.
