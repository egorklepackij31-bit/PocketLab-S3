# Карта памяти и Wi-Fi

## Раскладка microSD

После копирования папки `sd` в корень карты должно получиться так:

```
/wifi.txt              данные Wi-Fi
/maps/minsk.bmp        офлайн-карта Минска, 1536x1024, 24 бита
/maps/minsk.geo        привязка карты к координатам
/logs/                 журнал событий, создаётся сам
/wardrive/             CSV со сканированием Wi-Fi, создаётся сам
/subghz/               записанные пульты, создаётся сам
/ir/                   записанные ИК-коды, создаётся сам
```

Файловая система FAT32. Карта должна быть вставлена до включения устройства.

## Wi-Fi

Файл `/wifi.txt` в корне карты:

```
ssid=МояСеть
pass=МойПароль
```

Правила:

- одна строка - один параметр;
- строки с `#` или `;` в начале игнорируются;
- кодировка UTF-8 без BOM;
- поддерживается только диапазон 2.4 ГГц;
- пароль чувствителен к регистру.

Если файла нет, прошивка создаст шаблон при первом запуске. Пока сеть не задана, онлайн-пункты показывают подсказку.

Альтернатива без карты - файл `include/secrets.h`:

```cpp
#pragma once
#define WIFI_SSID "МояСеть"
#define WIFI_PASS "МойПароль"
```

Файл на карте важнее значений из `secrets.h`. Не выкладывайте `secrets.h` в открытый доступ.

## Карта Минска

Готовая карта лежит в `sd/maps`. Размер 1536x1024, 24-битный BMP без сжатия, около 4.5 МБ. Рядом лежит `minsk.geo` с границами:

```
lat_top=54.0077688
lon_left=27.3339844
lat_bottom=53.8006508
lon_right=27.8613281
```

`MapView` читает карту построчно, целиком в память не загружает. Если рядом с BMP нет `.geo`, карта открывается как картинка без координат и точек GPS.

## Своя карта

Скрипт `tools/download_map.py` собирает BMP из тайлов OpenStreetMap и пишет `.geo`:

```powershell
python tools/download_map.py
python tools/download_map.py --zoom 13 --name center --bbox 53.88,27.48,53.93,27.62
```

Требуется Python 3 и Pillow:

```powershell
pip install pillow
```

Не скачивайте тайлы массово. Скрипт кеширует загруженное в `tools/.tilecache` и ограничивает количество новых тайлов. При публикации карт указывайте (c) OpenStreetMap contributors.

## Точки на карте

Точки сохраняются в `/maps/waypoints.csv`:

```
minsk.bmp;768;512;53.9023;27.5619;1730000000
```

Поля: имя карты, X, Y в пикселях, широта, долгота, время. Файл можно редактировать вручную, но не меняйте порядок полей.
